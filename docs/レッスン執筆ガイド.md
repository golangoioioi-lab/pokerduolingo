# レッスン執筆ガイド（サブエージェント向け）

Holdem Lab は「ポーカー版 Duolingo」。日本語のテキサスホールデム学習アプリ（6人卓・100bb キャッシュが基本）。

## ファイル
- 本文: `src/domain/content/lessons/free/<id>.ts` または `.../pro/<id>.ts`（フォルダで無料/Pro が決まる）
- 形式は既存ファイルと同じ（例: `src/domain/content/lessons/pro/4bet.ts` を最初に読む）:
  ```ts
  import type { LessonBody } from '../../types';
  const lesson: LessonBody = { id: '<id>', blocks: [ ... ] };
  export default lesson;
  ```
- ブロックの型は `src/domain/content/types.ts`。計算・検査は `src/domain/content/diagrams.ts`
- 新コースのメタデータは `scripts/spec-parts/<番号>-<course-id>.json` に書く（`catalog-spec.json` と `catalog.ts` は直接編集しない）:
  ```json
  { "courses": [{ "id": "...", "title": "...", "level": "初心者|初級|中級|上級|全レベル", "symbol": "1文字", "description": "1文", "lessons": ["id1", "id2"] }],
    "lessons": { "id1": { "title": "...", "summary": "1文" } } }
  ```
- 無料/Pro: 初心者・初級コースは全部 free。それ以外は各コース最初の2本が free、残りは pro
- レッスン ID はコースごとの接頭辞付き（例 `pos-utg-open`）。既存 ID と重複しないこと

## 1レッスンの構成
- 本文は短め（800〜1500 字）、`h` 見出し 3〜5 個
- **図を2つ以上**（`pot` `equity` `odds` `seats` `combos` `timeline` `tree` `compare` のどれか。`cards` `range` `table` は図の数に含めない）。文章で説明するより図で見せる
- クイズ（`quiz` / `estimate`）3〜4 問（`explain` で理由を必ず書く）。選択肢は表示時に並び替えられるので順番は気にしない
- 最後に `tip` でまとめ、または `try`（tab: train / ranges / equity）で練習へ誘導してよい
- `range` の spot は `rfi-utg rfi-hj rfi-co rfi-btn rfi-sb btn-vs-co sb-vs-btn bb-vs-btn` のみ

## 直感で学べるようにする（最優先）
文字で説明するより、見て・触って分かる形にする。
- 本文の段落は短く（1段落2〜3文）。図で言えることは文章で繰り返さない
- クイズの半分以上を「見て答える」形にする:
  - `quiz` に `hand` / `board` を付けて、カードを見せて問う
  - `quiz` に `optionCards`（選択肢ごとのカード）を付けて、カードをタップして答える（例: どちらが強い？ どのハンドでコールする？）
  - `estimate`（スライダーで数字を見積もる）: 必要勝率、勝率、コンボ数、アウツなど。`tolerance` は答えの幅（範囲の1/4以下）
- `odds` 図は学習者がベット額を動かせる（自動）。ポットオッズの説明には `odds` を使う

## 図ブロックの書き方
- `odds`: `pot` はベット前のポット、`bet` はコール額。必要勝率は自動計算（bet/(pot+2·bet)）されるので本文の数字と合わせる
- `equity`: 合計 100%（±1）。数値はエクイティ計算で妥当な値に（不明なら「目安」と本文に書く）
- `combos`: ハンドは `AA` `AKs` `AKo` `AK`（高いランクが先）。`dead` にボードやブロッカーを入れると自動で減る
- `tree`: `outcomes` の prob 合計 1。EV は自動計算（単位 bb）
- `seats`: 席は UTG→HJ→CO→BTN→SB→BB の順、不要な席は省略可。`hero: true` は1席まで
- `timeline`: 全ストリートのボード合計 5 枚まで、カード重複なし
- カード表記: ランク `AKQJT98765432` ＋ スート `s h d c`（例 `As` `Td`）

## 文体と正確さ
- です・ます。短い文。煽らない。「〜しましょう！」の連発や絵文字は禁止。AIっぽい定型句（「いかがでしたか」「重要なポイントは」）も使わない
- 強調は `**太字**` のみ
- ポーカー的に正しいこと。ソルバー由来の数字は丸めて「目安」と書く。計算は自分で検算する
- クイズの正解は本文から導けること
