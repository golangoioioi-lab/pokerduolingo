# 公開手順

ほぼ自動です。手作業は「ログイン」「Google のクライアント ID のコピー」「Stripe の鍵の入力」だけです。

## 初回（1回だけ・約15分）

```bash
npm run setup
```

画面の案内に答えていくと、次を順番に自動で行います。途中で止めても、もう一度実行すれば終わったところは飛ばして続きから進みます。

| # | 内容 | あなたがすること |
|---|---|---|
| 1 | ツールの確認 | なし |
| 2 | Cloudflare にログイン | 開いたブラウザで「Allow」（アカウントがなければ作成） |
| 3 | データベース作成・テーブル作成・レッスン登録 | なし |
| 4 | 公開先（Pages）の作成、URL の設定 | なし |
| 5 | Google ログインの設定 | Google Cloud でクライアント ID を作ってコピー（画面に手順が出ます。スキップ可） |
| 6 | Stripe の商品・価格・Webhook・解約画面の作成と鍵の登録 | Stripe のシークレットキーと価格（円）を入力（スキップ可） |
| 7 | ビルドして公開 | なし |

- 秘密の値（Stripe の鍵、Webhook の署名シークレット）は画面に表示されず、Cloudflare に直接登録されます。ファイルにも残りません
- 最初は Stripe の **テスト用の鍵**（`sk_test_…`）で試してください。テスト用カード `4242 4242 4242 4242` で購入できます

## 2回目以降の更新

```bash
npm run deploy
```

テスト → データベース更新（テーブル・レッスン本文）→ ビルド → 公開 を1回で行います。

## push するだけで自動公開（任意）

GitHub に非公開リポジトリを作って push すると、`main` への push ごとに自動で公開されます（`.github/workflows/deploy.yml`）。最初に GitHub のリポジトリ → Settings → Secrets and variables → Actions で、次を登録します。

| 種類 | 名前 | 値 |
|---|---|---|
| Secret | `CLOUDFLARE_API_TOKEN` | Cloudflare → My Profile → API Tokens →「Edit Cloudflare Workers」テンプレートに「D1: Edit」を追加して作成 |
| Secret | `CLOUDFLARE_ACCOUNT_ID` | Cloudflare ダッシュボード右側の Account ID |
| Variable | `VITE_GOOGLE_CLIENT_ID` | setup で入力したクライアント ID |
| Variable | `VITE_PRICE_MONTHLY_JPY` / `VITE_PRICE_YEARLY_JPY` | setup で入力した価格 |

## 公開前チェック

- [ ] 特定商取引法の表記・利用規約の `[ ]` を埋めた（`src/pages/me/LegalPage.tsx`）
- [ ] テスト用の鍵で、ログイン → 購入 → Pro 反映 → 解約 → 退会 まで確認した
- [ ] 本番開始時: Stripe を本番モードにして `npm run setup` を再実行（「設定し直しますか」に y、`sk_live_…` を入力）
- [ ] Cloudflare の WAF で `/api/*` にレート制限（例: 同じ IP から 1分 60 回まで）

うまくいかないときの手動手順は [バックエンド構築手順.md](バックエンド構築手順.md) にあります。
